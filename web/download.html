First time opening it

The installers aren't signed with a paid certificate yet, so your computer asks once.

  1. Windows: if SmartScreen appears, click More info → Run anyway.
  2. macOS: right-click DupeSort in Applications → Open → Open. On recent versions, use System Settings → Privacy & Security → Open Anyway.
  3. License: everything works for 30 days. After that you can still scan and see the results; moving, tagging and converting need a license key (Help → Activate DupeSort…).
  4. Optional: install Chromaprint to match songs by sound, and FFmpeg for videos and audio conversion.
