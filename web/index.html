Find duplicates

Free, with no sign-up. Files are read on this device; nothing is uploaded.

Folders

This browser can read folders but not change them, so DupeSort shows what it finds and lets you save a report. To move duplicates into a _Duplicates folder, use Chrome or Edge on a computer, or the desktop app.

Find duplicate music, photos, videos and documents

Add the folders to check, then press Scan folders. DupeSort ticks the best copy in each group, and in Chrome or Edge moves the rest into a _Duplicates folder. Nothing is deleted, and you can undo.
