DupeSort User Guide

DupeSort finds duplicate music, photos, videos and documents, moves the extra copies out of the way, organizes what's left, and converts files between formats. Nothing is ever deleted, and every change can be undone.

1. Getting started

The sidebar on the left has one section for each kind of file: Music, Photos, Videos and Documents. It also has History and Help & Support. Each section works the same way:

  1. Click Add folder… and choose the folders to check (for example your Music folder and an old backup drive). DupeSort remembers them.
  2. Press Scan. Large libraries can take a few minutes. The bar at the bottom shows progress, and Cancel stops the scan.
  3. Review the results and choose what to do. The tabs along the top of each section hold the tools.

2. Finding and moving duplicates

Results appear in groups. Each group is a set of files that are the same, and the reason column says how they matched:

ReasonMeaning
Identical fileByte-for-byte the same file.
Same artist & titleSongs with the same artist and title, and a length within 3 seconds.
Same soundThe same recording identified by its audio fingerprint, even in a different format or bitrate (e.g. an MP3 and a FLAC).
Similar imageThe same photo resized, re-saved or slightly edited.
Same videoThe same video re-encoded at another size or quality.
Same textDocuments with the same text, e.g. a Word file and its PDF.

Ticked files are kept. DupeSort ticks the best copy in each group: the highest quality (lossless audio, higher bitrate, larger resolution), preferring originals over files named "copy" or "(1)". To change this, use Keep which copy (best quality, oldest, newest or shortest path), or tick and untick files yourself. Every group always keeps at least one file.

Click a file to see details on the right (photos show a preview). Open plays or views it, and Show in folder reveals it.

Press Move duplicates to _Duplicates. Unticked files move into a _Duplicates folder inside the scanned folder, keeping their sub-folders. Look through that folder, then delete it yourself when you're sure.

Tip: Similarity tolerance (photos, videos) and Same text if at least (documents) control how strict matching is. Lower values mean only very close matches.

3. Music: tags, lyrics, renaming

Open the Tags, lyrics & rename tab after scanning.

  1. Choose Songs with missing details or All scanned songs, then press Look up tags & lyrics online. DupeSort searches MusicBrainz for the title, artist, original album, year, track number, genre and cover art, and LRCLIB for lyrics.
  2. Green rows ("Confident") are ticked automatically. Orange rows ("Please review") were uncertain: click one, pick another match from Online matches or type the details yourself, then press Use these details.
  3. Press Apply ticked. Tags, cover art and lyrics are written into the files. If Rename files is ticked, files are renamed to Artist - Title.

Rename all scanned songs (no lookup) renames using the tags the files already have. You can change the name pattern in Settings, for example {tracknumber} - {title}.

MusicBrainz allows one request per second, so a first lookup of 1,000 songs takes about 30-45 minutes. Each artist's albums are remembered, so later songs by the same artist are quicker.

4. Photos and videos: organizing by date

The Organize by date tab moves files into folders such as 2024/07. The date comes from, in order: the camera's own data (EXIF), a date in the file name (IMG_20240715_…, VID-20240715-WA0003), then the file's modified date. Press Preview changes to see every move, untick any you don't want, then press Move into date folders. You can change the folder pattern, e.g. {year}/{year}-{month:02d}.

5. Movie and TV names

In Videos → Movies & TV names, DupeSort reads names like Blade.Runner.1982.1080p.BluRay.mkv or The.Office.S02E05.mkv and renames them to Blade Runner (1982).mkv or The Office - S02E05 - Episode name.mkv using TMDb. This needs a free TMDb API key (see Settings and free API keys).

6. Documents: sorting by type

Documents → Sort by type moves files into PDF, Word, Spreadsheets, Presentations, Text and eBooks folders.

7. Converting files

Every section has a converter tab. Add files with the buttons, by dragging them in, or with Add scanned files. Choose whether to save the new files next to the originals or in a folder. Originals are never changed. If a name is already taken, the new file gets a number.

Music → Convert

FormatBest for
MP3Plays everywhere.
AAC (M4A)Apple devices; better quality than MP3 at the same size.
OpusSmallest files at good quality (Android, web).
Ogg VorbisOpen format, games, Linux.
FLAC / ALACLossless: perfect quality, bigger files, ideal for archiving.
WAVUncompressed, for editing software.

Bitrate: 128 kbps is fine for speech, 192-256 kbps for music, and 320 kbps is the highest MP3 quality. With Never raise the bitrate above the original on, a 128 kbps song is never re-encoded at 320 kbps, which would only make it bigger without sounding better. Tags, lyrics and cover art are copied to the new file.

Photos → Convert & resize

  • Save as JPEG (photos, small), PNG (graphics, screenshots, transparency) or WebP (modern, smallest). iPhone HEIC photos can be converted too.
  • Smaller files: lower the Quality (75-85 looks the same for most photos), use Fit within pixels (2048 px is plenty for sharing), or tick Reduce PNG colours.
  • Higher resolution: Upscale 2×/4× (simple) enlarges smoothly and instantly. Upscale 2×/4× (AI) uses Real-ESRGAN to add real detail. It's slower, and is downloaded once (about 50 MB) the first time you use it.
  • Remove camera & GPS location data before sharing photos publicly.

Videos → Convert & resize

  • Format: MP4 plays everywhere. MOV is for Apple, MKV for archives, WebM for websites, and AVI for old players.
  • Video codec: H.264 (most compatible), H.265 (about half the size, newer devices), VP9 or AV1 (smallest, slow to convert).
  • Resolution: e.g. 1080p or 720p, measured on the shorter side, so vertical videos work too.
  • Aspect ratio: 16:9 (YouTube/TV), 9:16 (Reels, TikTok, Shorts), 1:1 (square), 4:5 (portrait posts), 4:3, or 21:9. Fit adds black bars, Fill crops the edges, and Stretch distorts.
  • Quality / size: Small file is great for messaging, High quality for keeping.

8. History and undo

Every move, rename and tag change is recorded on the History page. Select one or more entries and press Undo selected. Files go back where they were and earlier tags are restored. Converting only creates new files, so it doesn't appear in History. To undo a conversion, delete the new files.

9. Appearance: themes, light and dark mode

Use View → Appearance or Settings. Choose Light, Dark, or System (follows your computer's setting), and an accent colour. The default, Mono, keeps the app black-and-white; the others are Sky, Pink, Indigo, Teal, Green, Orange, Purple or Slate. Changes apply immediately. You can also turn the animated intro on or off.

10. Settings and free API keys

  • TMDb API key (movie/TV names): create a free account at themoviedb.org, then go to Settings → API.
  • AcoustID API key (identify songs with no tags by their sound): register an application at acoustid.org.
  • Music lookups, cover art and lyrics need no key.
  • Ignore files smaller than and Skip paths containing keep scans focused.

11. Questions and troubleshooting

macOS says DupeSort "can't be opened" or is from an unidentified developer

Right-click DupeSort in Applications and choose Open, then Open again. On recent macOS versions, use System Settings → Privacy & Security → Open Anyway. You only need to do this once.

Windows SmartScreen warns about the installer

Click More info → Run anyway.

"Same sound" or video matching is unavailable

The installers include the helper tools (fpcalc and FFmpeg). If you run DupeSort from source, install them: macOS brew install chromaprint ffmpeg, Linux sudo apt install libchromaprint-tools ffmpeg.

A song got the wrong details

Open History and undo it, or look it up again and pick another match from the orange row. Songs with a title but no artist are never applied automatically, because a title alone matches many cover versions.

Where are my settings and history stored?

In your user app-data folder. History → Open history folder shows it. Settings are kept when you uninstall or upgrade.

12. Getting support

Open Help & Support in the sidebar and press Contact support by email. A message to the developer opens with your DupeSort version and system already filled in. Please describe what you did, what you expected, and what happened.
